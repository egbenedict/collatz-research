## 2. Stopping times and "almost all" results

| # | Work | Notes | 📖 |
|---|---|---|---|
| 2.1 | ⚠️ R. Terras, "A stopping time problem on the positive integers," *Acta Arith.* 30 (1976). | Almost all n (density 1) eventually drop below n. Introduces parity vectors and the mod 2ᵏ bijection. | |
| 2.2 | ⚠️ C. J. Everett, "Iteration of the number-theoretic function f(2n)=n, f(2n+1)=3n+2," *Adv. Math.* 25 (1977). | Proved the same result independently. | |
| 2.3 | ⚠️ I. Korec, "A density estimate for the 3x+1 problem," *Math. Slovaca* 44 (1994). | Almost all n reach a value below n^c for any c > log 3 / log 4 ≈ 0.7925. | |
| 2.4 | ✅ T. Tao, "Almost all orbits of the Collatz map attain almost bounded values," [arXiv:1909.03562](https://arxiv.org/abs/1909.03562) (read v7, Jul 2026); *Forum Math. Pi* 10 (2022). | **Read in full; notes in `notes/tao2019.md`.** For any f(n) → ∞, almost all n (logarithmic density) have orbit minimum below f(n); quantitative form: exceptions ≪ (log N₀)^(−c). The method also proves the same for 3x−1, so it can never give "reach 1" on its own (notes §4). | ✔ |
| 2.5 | ⚠️ T. Tao, blog post "The Collatz conjecture, Littlewood-Offord theory, and powers of 2 and 3" (2011) and the 2019 post on 2.4. | Readable sketches of the ideas behind 2.4. | |

## 3. Cycles

| # | Work | Notes | 📖 |
|---|---|---|---|
| 3.1 | ⚠️ C. Böhm, G. Sontacchi, "On the existence of cycles of given length in integer sequences like x_{n+1}=x_n/2 if x_n even, and x_{n+1}=3x_n+1 otherwise," *Atti Accad. Naz.
